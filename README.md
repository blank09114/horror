# HORROR(가제)

공포 분위기 연출을 목적으로 제작한 웹 인터랙티브 페이지입니다.

---
## 프로젝트 개요

사용자 클릭을 중심으로 오디오, 팝업, 노이즈 효과가 동작하는 체험형 웹 인터랙티브 페이지입니다. 클릭 시 배경음 및 효과음이 재생되고, 무작위 메시지가 팝업 형태로 출력되도록 구성해 불안감과 긴장감을 유도하는 방향으로 설계했습니다. 클라이언트가 제공한 기획과 디자인을 기반으로 구현을 단독으로 진행했습니다.

- 개발 형태: 웹 인터랙티브 페이지
- 개발 인원: 1인(외주 단독 개발)

## 구조 및 설계
### 인터랙션 구조

페이지 클릭을 중심으로 여러 효과가 동시에 동작하도록 구성했습니다. 사용자가 화면을 클릭하면:
- 배경음 재생
- 효과음 출력
- 메인 이미지 교체
- 랜덤 메시지 팝업 생성
이 하나의 흐름 안에서 연속적으로 실행됩니다.

### 팝업 구조

팝업은 별도의 popup.html 페이지로 구성하고, `window.open()`과 `postMessage()`를 활용해 부모 창에서 자식 창으로 메시지를 전달하는 방식으로 구현했습니다. 팝업 내부에서는 전달받은 메시지를 출력하고, 닫기 버튼 및 obey 버튼을 통해 창을 종료할 수 있도록 구성했습니다.

### 비주얼 연출

Canvas API를 활용해 픽셀 단위 grayscale 노이즈를 실시간으로 생성하도록 구현했습니다. 또한 클릭 시 메인 이미지를 교체하고 일정 시간 후 원래 상태로 복구되도록 처리해 시각적인 변화가 즉각적으로 체감되도록 구성했습니다.

## 구현
### 랜덤 메시지 시스템

문구 배열을 기반으로 클릭 시 무작위 메시지가 선택되도록 구현했습니다. 선택된 문구는 팝업 창으로 전달되며, 매 클릭마다 다른 메시지가 출력되도록 처리했습니다.

### 오디오 처리

Audio API를 활용해 배경음과 효과음을 제어했습니다. 첫 클릭 시에만 배경음이 재생되도록 상태 플래그를 사용했으며, 효과음은 클릭마다 다시 재생될 수 있도록 `currentTime`을 초기화한 뒤 실행했습니다.

### Canvas 노이즈 효과

Canvas의 `ImageData`를 활용해 픽셀 단위 랜덤 grayscale 값을 생성했습니다. 생성된 노이즈는 `requestAnimationFrame()` 기반 루프를 통해 지속적으로 갱신되며, CRT 화면과 유사한 시각적 효과를 연출하도록 구성했습니다.

### 이벤트 처리

`DOMContentLoaded`, `click`, `resize`, `message` 이벤트를 활용해 사용자 상호작용과 UI 상태 변화를 처리했습니다. 특히 resize 이벤트를 통해 Canvas 크기를 화면 크기에 맞게 동적으로 조정하도록 구현했습니다.

---
## 개선점

Canvas 노이즈를 매 프레임 생성하는 방식은 화면 크기가 커질수록 성능 부담이 증가할 수 있습니다. 현재는 단순 grayscale 노이즈 기반으로 처리했지만, 이후에는 렌더링 최적화 및 FPS 제한 등을 고려할 수 있습니다.
